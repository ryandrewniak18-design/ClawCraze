# 🛍️ How to Add Your ClawCraze Landing Page to Shopify

## ✅ Your File is Ready!

**File Location:** `/app/shopify-export/clawcraze-landing-page.html`

This is a **100% Shopify-compatible** standalone HTML file. All images are hosted externally, so you can paste it directly into Shopify.

---

## 📋 Step-by-Step Instructions

### Method 1: Paste as a Shopify Page (Recommended - 2 minutes)

**Step 1: Copy the HTML**
1. Open the file `/app/shopify-export/clawcraze-landing-page.html`
2. Select ALL content (Ctrl+A or Cmd+A)
3. Copy it (Ctrl+C or Cmd+C)

**Step 2: Create Shopify Page**
1. Log into your Shopify Admin
2. Go to **Online Store** → **Pages**
3. Click **Add page** button

**Step 3: Add the HTML**
1. Give your page a title: `Magic Curl Cat Scratcher` (or anything you like)
2. In the content editor, click the **Show HTML** button (looks like `< >`)
3. **Delete** any default content in the HTML editor
4. **Paste** your copied HTML (Ctrl+V or Cmd+V)
5. Click **Save**

**Step 4: Publish**
1. Make sure the page is set to "Visible"
2. Click **Save** again
3. Done! 🎉

**Your page URL will be:**
`https://your-store.myshopify.com/pages/magic-curl-cat-scratcher`

---

### Method 2: Add to an Existing Page

If you want to add this to an existing Shopify page:

1. Open your existing page in Shopify Admin
2. Click **Show HTML**
3. Paste the HTML where you want the landing page to appear
4. Save

---

### Method 3: Add to Homepage (Advanced)

If you want this as your homepage:

1. Go to **Online Store** → **Themes**
2. Click **Actions** → **Edit code**
3. Find your `index.liquid` or home template
4. Replace the content with the HTML (or add a new section)
5. Save

## 🎨 Customization After Pasting

### Update the Buy Link (Important!)

The "Buy Now" button currently links to:
```
https://www.aliexpress.us/item/3256810331285360.html
```

**To change to your Shopify product:**

1. After pasting into Shopify, stay in HTML mode
2. Press Ctrl+F (or Cmd+F) to open Find
3. Search for: `aliexpress.us`
4. Replace with your Shopify product URL, like:
   ```
   /products/magic-curl-cat-scratcher
   ```
   or full URL:
   ```
   https://clawcraze.myshopify.com/products/magic-curl-cat-scratcher
   ```
5. Replace ALL instances (there should be 1 main one in the CTA section)
6. Save

### Change Pricing

If you want to change the price from $14.99:

1. In HTML mode, search for: `$14.99`
2. Replace with your price
3. Also update the "was $29.99" if needed
4. Save

### Update Brand Name

To change from "ClawCraze":

1. Search for: `ClawCraze`
2. Replace with your store name
3. Save

## 🚨 Troubleshooting

**Problem: Images not showing**
- Solution: Images are externally hosted and should work. If not, check your browser's ad blocker.

**Problem: Styling looks broken**
- Solution: Make sure Tailwind CSS CDN is loading. Check your internet connection.

**Problem: Smooth scrolling not working**
- Solution: This is normal in Shopify's preview. It will work on the live page.

**Problem: Buy button doesn't work**
- Solution: Make sure you updated the AliExpress link to your Shopify product URL (see "Update the Buy Link" above)
