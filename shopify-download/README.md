## 🚀 Quick Install (2 Minutes)

### Option 1: Add as Shopify Page (Easiest)

1. Login to Shopify Admin
2. Go to **Online Store** → **Pages** → **Add page**
3. Open `clawcraze-landing-page.html` from this folder
4. Copy ALL the content
5. In Shopify, click "Show HTML" button
6. Paste the HTML
7. Click Save
8. Done! 🎉

### Option 2: Add to Homepage or Existing Page

1. Open your existing Shopify page
2. Click "Show HTML"
3. Paste the content from `clawcraze-landing-page.html`
4. Save
