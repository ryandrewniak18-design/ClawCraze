## 🚀 How to Upload to Shopify

### Method 1: Upload ZIP Directly (Easiest)

1. **Download the ZIP**
   - Location: `/app/ClawCraze-Shopify-Theme.zip`

2. **Go to Shopify Admin**
   - Navigate to: **Online Store** → **Themes**

3. **Upload Theme**
   - Scroll down to "Theme library"
   - Click **Add theme**
   - Click **Upload ZIP file**
   - Select `ClawCraze-Shopify-Theme.zip`
   - Click **Upload**

4. **Wait for Upload**
   - Shopify will process and install the theme
   - Takes about 30 seconds

5. **Activate Theme**
   - Once uploaded, click **Actions** → **Publish**
   - Or click **Preview** to see it first

**Done! Your ClawCraze landing page is now live! 🎉**

---

### Method 2: Upload from GitHub

If you pushed this to GitHub:

1. **In Shopify Admin**
   - Go to: **Online Store** → **Themes**

2. **Add Theme from GitHub**
   - Click **Add theme** → **Connect from GitHub**
   - Select your repository
   - Select branch: `main` (or your branch name)
   - Click **Connect**

**Important:** Make sure the theme files are in the ROOT of your repo, not in a subfolder!

## 🎯 After Uploading

### Customize the Buy Button

The "Buy Now" button currently links to AliExpress. To change it:

1. After uploading, go to **Online Store** → **Themes**
2. Click **Actions** → **Edit code**
3. Find `sections/landing-page.liquid`
4. Search for: `https://www.aliexpress.us/item/3256810331285360.html`
5. Replace with your Shopify product URL:
   - `/products/magic-curl-cat-scratcher` (relative URL)
   - or full URL: `{{ shop.url }}/products/magic-curl-cat-scratcher`
6. Click **Save**

### Update Pricing

1. In `sections/landing-page.liquid`
2. Find: `$14.99`
3. Replace with your price
4. Save

## 🔧 Troubleshooting

**"File not found" error:**
- Make sure you're uploading `ClawCraze-Shopify-Theme.zip`
- Don't rename the zip file

**"Invalid theme" error:**
- Make sure the ZIP contains the `clawcraze-theme` folder
- Don't extract the zip before uploading

**Images not loading:**
- Images are hosted externally and should work
- Check your internet connection

**Want to add more pages:**
1. Go to **Themes** → **Actions** → **Edit code**
2. Add new templates in the `templates/` folder
3. Create new sections in the `sections/` folder
